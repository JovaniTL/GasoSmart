# GazoSmart ⛽🚗

GazoSmart es una aplicación móvil desarrollada para Android utilizando **Jetpack Compose** y **Material 3**. Su objetivo principal es ayudar a los usuarios a encontrar gasolineras, comparar precios, calcular costos de combustible, reportar y consultar niveles de saturación en filas, así como evaluar la calidad del servicio (atención, limpieza y rapidez).

---

## 🚀 Características Principales

- **Catálogo de Gasolineras:** Explora una lista detallada de gasolineras disponibles.
- **Detalle de Gasolinera:** Visualiza información de contacto, dirección, municipio, promedios de evaluaciones y el último reporte de saturación junto con su historial.
- **Comparador de Precios:** Compara los precios del combustible entre distintas estaciones para tomar la mejor decisión.
- **Calculadora de Combustible:** Estima costos y cantidades de combustible de manera rápida.
- **Reportes de Saturación:** Consulta y reporta el nivel de vehículos en espera y el tiempo estimado de fila (Baja, Media, Alta).
- **Evaluaciones de Servicio:** Califica y revisa métricas de atención, limpieza y rapidez del servicio en cada estación.
- **Recomendaciones:** Obtén sugerencias inteligentes basadas en tus necesidades.

## 🛠️ Cómo Ejecutar el Proyecto

1. Clona este repositorio.
2. Abre el proyecto en Android Studio.
3. Espera la sincronización de Gradle.
4. Inicia un emulador o conecta un dispositivo Android.
5. Ejecuta la aplicación con Run ▶️.
